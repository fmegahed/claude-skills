# Probe: Miami palette contrast

This folder holds the script that measures WCAG 2.x contrast ratios for the Miami University palette. The palette comes from https://miamioh.edu/brand/style/ (read 2026-10-19).

| File | What it measures |
|---|---|
| `contrast.mjs` | The contrast ratio of text and background pairs of the palette. |
| `output.txt` | The output of the script. |

## Run

```
node contrast.mjs > output.txt
```
